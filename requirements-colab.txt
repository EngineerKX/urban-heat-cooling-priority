# Trimmed requirements for Colab training sessions
# (notebooks/colab_training/train_unet.ipynb, train_heat_cnn.ipynb).
# Installed fresh each ephemeral Colab session, so kept minimal for a fast
# `pip install` -- not a copy of requirements.txt.
#
# Deliberately EXCLUDES:
#   - torch: Colab ships a pre-installed, CUDA-matched torch build already.
#     Installing the local CPU-only pin from requirements.txt here risks
#     silently replacing it with a mismatched wheel and losing GPU accel --
#     the one thing training in Colab is for.
#   - tensorflow: this project no longer uses it at all (see the
#     TensorFlow->PyTorch migration) -- never needed here either.
#   - app-only packages (streamlit, streamlit-folium, folium, plotly,
#     altair, pydeck, watchdog, GitPython, gitdb) and non-DL packages
#     (xgboost, scikit-learn) that the Streamlit app / RF+XGBoost need but
#     these training notebooks never touch.
#   - version pins on numpy/requests/google-auth: Colab's base image
#     ships these pre-installed at versions its own `google-colab` package
#     (which the auth cell's google.colab.files.upload() call depends on)
#     explicitly requires. Forcing our locally-pinned versions here
#     overwrites them and risks breaking that call -- confirmed via a real
#     pip dependency-conflict warning during an actual Colab run
#     (2026-08-05). Left unpinned so pip only touches them if some other
#     package in this list truly needs a newer one.
